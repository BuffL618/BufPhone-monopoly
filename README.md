# 手机大富翁记分器

一个适配手机浏览器的大富翁记分器。创建房间后，同一局域网内的玩家可以扫码进入同一个房间，所有操作会实时同步。

## 启动

```powershell
python server.py
```

启动后打开终端里显示的地址。创建房间后，点页面右上角的“扫码加入”，其他玩家扫码即可进入。

## 功能

- 最多 8 名玩家
- 开局统一设置初始资金
- 开局设置经过起点金额，玩家点“起点”后固定收入该金额
- 实时排名：现金 + 固定资产
- 玩家主题颜色：默认 8 色，支持用 RGB/RMG 编号自定义
- 买房：扣现金，并把购买金额计入固定资产
- 修改房产名称和过路费
- 升级房产：扣现金，并把升级金额计入固定资产
- 收钱：选择收款玩家、付款玩家和房产，按过路费强制转账
- 抵押：玩家现金为负时可选择房产并输入抵押价值，立即获得对应现金，该房产固定资产变为抵押价值
- 手动现金调整：用于经过起点、事件卡、罚款等临时收支
- 操作记录支持撤回自己的错误操作
- 地块盘点：统计收钱次数、累计收钱、单次收钱最高的地块和玩家

## 注意

房间数据当前只保存在运行中的服务内存里。关闭 `server.py` 后，本局数据会清空。
