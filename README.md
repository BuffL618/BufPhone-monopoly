# 手机大富翁记分器

一个适配手机浏览器的大富翁记分器。创建房间后，同一局域网内的玩家可以扫码进入同一个房间，所有操作会实时同步。

## 启动

```powershell
python server.py
```

启动后打开终端里显示的地址。创建房间后，点页面右上角的“扫码加入”，其他玩家扫码即可进入。

## 功能

- 最多 8 名玩家
- 开局统一设置初始资金
- 开局设置经过起点金额，玩家点“起点”后固定收入该金额
- 实时排名：现金 + 固定资产
- 玩家主题颜色：默认 8 色，支持用 RGB/RMG 编号自定义
- 买地：扣现金，并把购买金额计入固定资产
- 修改房产名称和过路费
- 建房子：扣现金，并把建房金额计入固定资产；四栋绿色房子后再建会变为一栋红色房子
- 收钱：选择收款玩家、付款玩家和房产，按过路费强制转账
- 同色集齐：可在土地上设置同色集齐金额，收钱时按建筑数量加收；红色房子按 5 栋计算，界面过路费默认展示最终金额
- 卖房：土地有房子时先卖房，卖房收入为建房金额的一半；红色房子卖出后变回四栋绿色房子
- 抵押与赎回：无房子的土地可抵押；赎回价格为抵押价值的 110%
- 手动现金调整：用于经过起点、事件卡、罚款等临时收支
- 操作记录支持撤回自己的错误操作
- 地块盘点：统计收钱次数、累计收钱、单次收钱最高的地块和玩家
- 房产总览：查看所有玩家土地，可按玩家或过路费排序

## 注意

房间数据当前只保存在运行中的服务内存里。关闭 `server.py` 后，本局数据会清空。
